# Glossary (use consistently)
POP -> POP ; Grade -> Note ; Money -> Argent ; time block -> bloc de temps ; rumour/rumor -> rumeur ; Ball -> bal ; "Sixth-Grade Last-Year Ball" -> bal de fin d'année de 6e année
